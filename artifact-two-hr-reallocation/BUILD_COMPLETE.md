## Reproducing the report from a clean clone

Requirements: Docker Desktop (or Docker Engine + Compose). No external network calls, no API keys —
every input is a checked-in CSV under `data/`.

```bash
git clone <this repo>
cd <cloned-directory>/artifact-two-hr-reallocation

# 1. Start Postgres and Airflow (standalone mode).
docker compose up -d postgres
docker compose up -d --build airflow

# 2. Wait for the webserver, then get the autogenerated admin password:
until curl -s -o /dev/null http://localhost:8081/; do sleep 5; done
docker compose logs airflow | grep -A1 "Password for user"

# 3. Unpause and trigger the DAG (id: borno_hr_reallocation):
docker compose exec airflow airflow dags unpause borno_hr_reallocation
docker compose exec airflow airflow dags trigger borno_hr_reallocation

# 4. Watch it run (load_csv -> dbt_seed -> dbt_run -> dbt_test -> optimize -> generate_report):
docker compose exec airflow airflow dags list-runs -d borno_hr_reallocation

# 5. Once it finishes, the transfer proposal report is at:
#    data_snapshots/borno_hr_reallocation_report.html  (open it in a browser)
#    ...and the same data is queryable directly:
docker compose exec postgres psql -U borno -d borno_hr_reallocation \
  -c "select * from dbt_marts.mart_reallocation_input order by lga;"
```

Postgres is bound to host port `5443` and the Airflow webserver to `8081` — both deliberately
distinct from `../artifact-one-data-quality`'s `5442`/`8080`, so the two artifacts can run side by
side without a port collision.

If you'd rather not run Airflow, every task it orchestrates is directly invocable the same way it
was developed and tested — see `airflow/dags/borno_hr_reallocation_dag.py`'s module docstring for
the exact task order and the underlying commands (`ingestion/load_csv.py`, `dbt seed`/`run`/`test`,
`optimizer/main.py`, `viz/generate_report.py`).

To re-run just the deterministic acceptance suite without Docker at all (it reads straight from
`data/*.csv`, per `tests/_test_support.py`):

```bash
python -m venv .venv && . .venv/Scripts/activate   # or source .venv/bin/activate on Linux/macOS
pip install pydantic psycopg[binary] scipy mypy ruff pytest pytest-cov
python -m pytest -v
python -m mypy
python -m ruff check . && python -m ruff format --check .
```
